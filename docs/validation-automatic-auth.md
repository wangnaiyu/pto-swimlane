## 用户可见变化

新对话发起「使用 pto-swimlane-mcp 分析性能」后，Agent 签发并打开新入口，页面自动兑换浏览器授权。用户可上传新文件，或在运行记录中选择任一仍保留的文件版本。新流程不要求点击「进入上传页面」或复制同步口令；用户下一次提问时，Agent 读取本对话的当前选择。网页不会主动发消息。

同一浏览器的不同对话保持独立选择；选择旧版本不改写共享分析的全局 active。新上传失败继续显示已选文件，成功后本对话才切换。仍有有效浏览器授权时，原重开链接跟随同一对话的最新选择；无授权时从 MCP 重新打开。原有 15 分钟一次性入口、24 小时浏览器授权、账号撤销与 7 天文件保留规则继续生效。

## 变更范围

- `src/remote/analysis-sessions.ts`：持久对话关联、版本选择、上传结果跟随与 revision 检查。
- `src/remote/http.ts`：新增 `get_analysis_session`、签发入口携带关联、自动兑换、按标签页解析上下文、旧链接恢复、历史版本选择。
- `src/remote-client.ts`、`App.vue`：自动进入、授权进度和恢复提示；新流程显示「已关联当前对话」，旧链接保留手工同步。
- `RunManager.vue`、`FileManager.vue`、`remote/state.ts`：使用历史文件入口、按文件版本选择和当前选择删除保护。
- 文档、版本号、App.vue 来源哈希、协议和浏览器测试同步更新。

本次沿用现有泳道 shell 和 PTO 控件，不做视觉系统迁移；解析器和上游原始哈希保持不变。安装脚本与账号凭据未修改。

## 部署与回滚

本文件不是线上已生效的声明。候选包已通过最终本机回归，取得部署授权后才能替换服务。部署前检查是否存在上传/解析任务，备份数据库并保留当前服务包；上线后用人工 L2 验证新对话入口、过期 Cookie、历史文件选择和实际 MCP 工具发现。

数据库仅新增 `analysis_sessions`、`analysis_grants` 表，不修改旧表列。旧服务可忽略新表继续使用原授权链路；回滚会暂时失去新工具和自动关联，但不要求删除文件或重置个人 token。账号重置/停用及到期删除规则保持原状。
